# Security & Privacy Policy
- Passwords are analyzed in memory only. They are never written to disk, logged, hashed-and-stored, or sent over a network.
- The dashboard binds to 127.0.0.1 only, rejects unexpected Host headers, sends no-store cache headers and a CSP.
- Optional history stores aggregate metadata only (time, score, label, length, bit estimate, finding categories).
- No cracking, brute-forcing, or credential-collection features exist, by design.
- Use synthetic passwords for demos, screenshots and tests. Report issues via a GitHub issue (no real passwords, please).
